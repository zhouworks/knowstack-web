# 知栈首页 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 将用户已确认的暖白书页首页实现为可访问、响应式的 Vue 页面。

**Architecture:** App 提供统一导航与页脚，HomeView 还原设计。Vue Router 承载栏目空状态、关于与不存在页面；书页图和字体本地加载。

**Tech Stack:** Vue 3、TypeScript、Vite、Vue Router、Phosphor 图标。

**Spec:** `../../design/home-design.md` 与 `../../design/home-reference.png`。

## Global Constraints

- 仅在现有 web 工程开发，不改服务端；复用当前干净的 checkout。
- 保留已确认中文文案与页面布局，必要处添加中文注释。
- 不虚构文章、项目或公开身份信息；不添加无效按钮。
- 仅以图片表现主视觉；支持 reduced-motion；不依赖外部运行时资产。
- 本次为可逆的页面实现，不引入单元测试框架；验证真实浏览器行为与已有构建/检查命令。

## Review Focus

- 375px / 320px 窄屏：导航可用、标题不溢出、操作按钮可点击。
- 直接访问栏目和不存在路径：展示正确页面，能返回首页。
- 键盘导航：可见焦点与跳转链接；路由切换后焦点进入主要内容。
- 字体与图片：加载失败时文字仍可读，图片有固定比例避免布局跳动。
- 无数据：明确空状态，不呈现假文章、假项目或占位外链。
