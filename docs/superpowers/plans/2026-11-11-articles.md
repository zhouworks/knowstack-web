# 文章列表与详情实现

依据根目录 `docs/requirements.md` 与 `docs/technical-design.md`，只推进首版文章阅读链路。

1. 建立 Markdown + YAML 内容校验与生成流程：草稿默认隐藏，摘要与正文分离，仅发布引用的本地图片。
2. 提供 ContentRepository 静态实现，列表与详情只依赖该接口。
3. 实现 `/blog` 和 `/blog/:slug`，沿用暖灰白与鼠尾草绿，覆盖加载、失败、空列表和不存在状态。
4. 支持安全 Markdown、稳定标题锚点、响应式正文、页面标题/描述及浏览历史滚动恢复。
5. 用真实文件夹测试内容规则、草稿隔离、图片清理；执行构建、静态检查与桌面/手机阅读验证。

真实文章尚未提供：提交一份默认草稿模板，不虚构已发布内容。视觉验收使用临时测试文章，完成后删除并重新生成。

实现细节：PostDetail 保留 bodyMarkdown，并携带 imageMap（原始相对引用到生成图片 URL 的映射）；渲染器统一改写图片 src。这样无需用字符串替换改动代码示例中的图片路径，后续 API 仍可返回 Markdown。
