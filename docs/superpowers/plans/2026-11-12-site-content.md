# 前端网站内容完善计划

**目标：** 补齐项目展示和关于页面，将公开内容集中维护，保持已确认的暖灰白风格。

**依据：** 根目录 `docs/requirements.md` 项目、关于及内容维护规则；用户授权先完成前端收尾。

**实现：** `content/site.json` 和 `content/projects.json` 为公开配置。共享校验器供构建命令和页面使用；项目卡片无链接时只展示内容，不生成占位按钮。项目不另开详情页。个人信息未提供则不展示个人资料区。配置中不存草稿/私密资料。

- [x] 配置及校验：先测试空项目、重复标识、错误状态、危险链接及可选个人资料，再实现校验并接入构建。
- [x] 页面：实现 ProjectCard / ProjectsView，扩展 AboutView，将首页、页脚、页面信息接入统一配置。
- [x] 真实内容：用户已确认展示本站及起草建站记录，并提供昵称、介绍和邮箱；文章保持草稿。
- [x] 验证：41 项测试、构建、静态检查、桌面/手机项目与关于页及首页回归通过。空配置由测试覆盖；完整键盘验收留待上线前执行，具体边界见 `docs/design/site-content-qa.md`。
- [x] 收尾：更新维护说明和验收记录；保留交付截图，核查临时文件。正式文章仍需站长审阅后发布。

采用 JSON 配置而非新增 CMS 或后端依赖；本次只推进现有前端范围。源码/演示链接按配置显示，不为填满布局添加虚构信息。实现在当前 checkout 完成，不自动提交用户代码。
