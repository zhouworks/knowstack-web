# 知栈首页设计

2026-11-11，用户确认采用第三版首页的暖灰白配色修订稿。

## 视觉依据

- 参考图：`home-reference.png`，保留其布局、文案、展开书页造型。
- 暖灰白背景、炭灰文字、灰绿色主按钮，珍珠白书页与柔和投影。
- 采用真实 HTML 标题、导航、按钮与页脚；图片仅承担装饰性主视觉。
- 桌面为左标题、右介绍与操作，下方通栏书页；手机依次为标题、介绍、操作、书页。
- 标题为「把思考，写成新的可能。」；简介为「这里是知栈，记录学习与开发中的思考，分享技术文章与项目实践。」。

## 范围与行为

- 沿用唯一 `web` Vue 3 + TypeScript + Vite + Vue Router 工程。
- 导航：首页 `/`、文章 `/blog`、项目 `/projects`、关于 `/about`。
- 首屏主要操作为「阅读文章」和「浏览项目」。
- 尚未提供真实文章、项目与个人资料，因此文章、项目展示空状态；关于页只展示已确认的网站定位。
- 不存在的路径显示返回首页入口；暂不实现内容读取、管理功能或后端调用。
- 不新增文章流、数据面板、主题切换或持续动画。仅按钮的短过渡，支持减少动态效果设置。
- 手机直接展示四个导航入口，无折叠菜单；键盘焦点可见，提供跳到主要内容链接。

## 方案取舍

已比较左右分栏书栈、居中晶栈、上方排版与下方书页三个方向。用户选择第三个，并确认从深色金属改为暖白书页的修订稿。
立体效果使用本地 WebP，优先保持图片表现与加载速度，无需引入实时 3D 引擎。
标题字体使用本地 Noto Serif SC 字形子集，保留 SIL OFL 许可证；界面使用系统无衬线字体。

## 验收

1. 桌面和手机都能直接识别四个栏目与两个主要操作。
2. 首页主要区域的排列、文案、色调、书页意象与参考图一致。
3. 栏目切换、返回、刷新与未知路径均有可理解的结果。
4. 类型检查、静态检查、构建通过；浏览器无应用错误。
5. 图片与字体均随构建发布，不依赖外部字体或图片服务。
