# 文章页面验收

验收日期：2026-11-11 至 2026-11-12。沿用已确认的暖灰白、鼠尾草绿与细线布局，不改变首页主视觉。

## 已验证

- 26 项 Vitest 测试通过：元数据错误、日期、排序、标签、草稿隔离、站内链接/锚点、图片复制与撤下清理、Markdown 安全、按需正文加载和失败重试。
- `npm run build` 通过，包括 TypeScript 检查与构建产物审查；ESLint、Oxlint 通过。
- 浏览器通过列表进入详情、直接访问及刷新详情、中文及重名标题锚点、导航选中状态与页面标题/摘要。
- 浏览器返回列表后滚动位置保持一致，实测返回前后均约 332.8px。
- 暂时移走一篇正文的构建文件时显示加载失败；恢复文件后点击“重新加载”，正文正常出现。故障注入文件已恢复并由最终构建替换。
- 390px 正文中代码与表格在各自容器横向滚动，页面无整体横向溢出；最终 320px 页面可用宽度和内容宽度均为 305px（扣除浏览器滚动条）。
- 不存在文章和草稿地址显示不存在状态。临时文章移除后，列表展示空状态，生成索引为 `[]`，生成图片目录为空。

## 边界

当前为客户端 SPA，部署时仍需要 history 路由回退；尚未接入后端，也不包含搜索、分页、评论或编辑后台。文章图片按需加载，首版不计算阅读时长、不提供复杂目录侧栏。真实慢网环境下的布局偏移与更大内容量的性能未做专项测量。
