# 知栈标志

采用用户确认的无外框「展开的书页 + 层叠」标志：左侧完整书页表达知识，右侧两片书页向上舒展，表达积累，与首页书页主视觉呼应。根据确认的设计预览整理为可缩放的 SVG 曲线，使用纯色填充。

相较于单独 K 字母，书页更贴近本站的阅读与记录；相较于汉字印章，简洁图形在浏览器的小图标中更易辨认。保留网站原有中文、英文文字标识，图形不代替站点名称。

- 深松绿：`#405b4c`，沿用按钮强调色。
- 中绿：`#6e8874`，右上书页。
- 浅叶绿：`#91a686`，右下书页。
- 米白：`#f3f2ed`，仅为页面及 Apple Touch 图标底色，不属于标志。
- SVG 母版：`public/brand/knowstack-mark.svg`，正方形 viewBox，三条独立书页路径，不依赖外部字体或图片，没有矩形、圆角外壳。
- PNG：`public/brand/knowstack-mark.png`，512 × 512，书页之外透明，适合分享与预览。
- ICO：`public/favicon.ico`，包含 16、32、48 三种尺寸，替换模板图标。
- Apple Touch：`public/apple-touch-icon.png`，180 × 180，不透明背景。

图形通过普通图片接入导航栏和页脚；链接保留文字名称，图形使用空 alt，避免读屏重复。HTML 显式声明 ICO、SVG 与 Apple Touch 图标。引用使用 `?v=2` 区分旧版缓存。

修改母版后，在已安装 Pillow 的 Python 环境执行 `python scripts/export-brand.py` 同步导出。脚本只覆盖上述派生图片，不参与正常前端构建，不新增 npm 依赖。当前导出器仅支持母版使用的绝对 M/L/C/Z 路径指令，读取同一 SVG 的曲线采样生成位图，避免分别维护两份轮廓。SVG 与 PNG 保留透明背景；Apple Touch 按平台展示习惯单独使用不透明页面底色。

验收包含生产构建、桌面与 320px 窄屏品牌布局、SVG/PNG/ICO 文件检查。浏览器若缓存了旧图标，可关闭旧标签并重新打开或清除该站点缓存。

本轮生产构建、TypeScript、内容产物审查、ESLint/Oxlint 通过。2026-11-13 完成无外框版本的桌面与 320px 手机预览检查，导航和页脚图片加载成功，没有横向溢出；可访问名称保留完整站名，页面声明三种新版图标资源，浏览器日志无错误。ICO 尺寸与透明通道、PNG 透明背景及源文件和构建产物一致性另经文件检查。iOS 真机主屏图标未实机验收。
