## 先把网站要表达的事情说清楚

知栈的定位是一个持续维护的个人技术网站：记录学习中的思考，整理开发实践，也展示逐步完善的项目。

首页先回答“这里是什么”，文章与项目各自放在独立栏目中。这让首次访问的读者可以先了解网站，再选择感兴趣的内容，而不必在首页面对大量信息。

## 让视觉服务于阅读

页面采用暖灰白背景与灰绿色强调色。首页保留展开书页的主视觉，在文字、图片和操作之间留出足够空间。

进入文章页面后，视觉重点回到标题、摘要和正文。宽代码块与表格在各自的区域内横向滚动，避免把手机上的整张页面撑宽。项目页则展示名称、简介、实际状态与技术标签；没有提供源码或演示地址时，不出现占位按钮。

## 用 Markdown 维护文章

当前文章保存在本地 Markdown 文件中，开头用 YAML 记录标题、摘要、日期和发布状态。页面组件负责展示，正文内容独立维护。

一篇文章的结构可以这样理解：

```text
content/posts/
  article-slug/
    index.md
    images/
      illustration.webp
```

草稿不会被放入公开的文章索引或正文模块。构建前会检查字段、日期、链接与图片引用，只生成已发布内容。文章列表读取摘要，详情页再按需加载正文。

本地图片以内容哈希命名，正文通过图片映射找到生成资源。这样的组织方式也为以后保留图片地址、迁移存储提供了基础。

## 保持简单，也给后续留出位置

现阶段使用 Vue 3、TypeScript 与 Vite，先完成公开页面和阅读流程。文章读取通过统一的内容仓库接口进行，后续可以在这个入口接入 Java 服务。

后端的接口与数据模型已经开始整理，但当前页面仍使用本地内容，不能把已有的接口文档当作已经运行的服务。接下来的工作会逐步覆盖数据库读取、真实接口联调和部署验证。

## 继续积累

网站的价值最终来自持续整理的内容。先让结构清晰、维护方便，再把遇到的问题、尝试和结论写下来，是知栈当前的建设方向。
